## 1. 簡報總覽

- 這份 deck 示範正式簡報的標準格式
- 你後續只要替換標題、日期、圖文與表格，就能快速生成同類型內容
- 這個範本同時示範圖片引用與表格排版

--

### 1.1 使用說明

- 圖片放在同資料夾的 `images/`
- 其他附件放在同資料夾的 `assets/`
- 表格可用 Markdown table，較複雜時可直接改成 HTML table
